---
title: CLI Application
---

`cliver` is the CLI application layered on `cliver-core`. The application package currently
provides CLIver's config-directory and skill-discovery conventions; the interactive CLI/TUI is
being built in later phases. Until then, use `cliver-core` directly from Python.

## Config Directory

The application resolves its config directory in this order:

1. `CLIVER_CONF_DIR`
2. `%APPDATA%/cliver` on Windows
3. `~/.cliver`

## Skill Sources

Skills are discovered from eight sources, with later sources overriding earlier ones by name:

1. Builtin skills shipped with the application
2. `{config_dir}/skills`
3. `~/.agents/skills`
4. Project-local `.cliver/skills`
5. Project-local `.agent/skills`
6. Project-local `.claude/skills`
7. Project-local `.gemini/skills`
8. Project-local `.qwen/skills`

The application ships four builtin skills: `brainstorm`, `write-plan`, `execute-plan`, and
`wbs-planner`.

## Workspace Development

```bash
make init     # install both packages
make test     # run the workspace test suite
```

The application's discovery code lives in `packages/cliver` and delegates parsing, validation,
and activation to `cliver-core`'s `SkillManager`.
