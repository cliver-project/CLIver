## Requirements

- **Python 3.10+**
- An API key for at least one LLM provider (or a local endpoint)

## Install cliver-core

`0.3.2` is the latest release of the 0.3 API series. The public API stays backward
compatible: `0.3.x` releases carry bug fixes and additive APIs, and breaking changes require a
new minor release. Pin the exact version when your deployment needs reproducibility:

```bash
pip install cliver-core==0.3.2
```

The core package includes the MCP client (stdio and streamable HTTP). See
[Stability & Versioning](../stability/) for the support policy.

## Install the CLI

The CLI is a separate package released from the same tag as the core, and it depends on the
matching `cliver-core` version:

```bash
pip install cliver
```

It provides the `cliver` command for one-shot tasks and an interactive REPL. See
[CLI Application](../../cli/) for configuration, skills, and permission behavior.

## Optional local models

In-process embedding, rerank, and System One backends pull torch, so they are opt-in:

```bash
pip install "cliver-core[local-st]==0.3.2"     # sentence-transformers embeddings
pip install "cliver-core[local-flag]==0.3.2"   # FlagEmbedding embeddings + rerank
pip install "cliver-core[local]==0.3.2"        # all three local backends
```

## Verify Installation

```bash
python -c "from cliver_core import AgentCore; print(AgentCore)"
```

## Work on the workspace

The repository is a uv workspace with two packages: `cliver-core` and the `cliver` CLI
application.

```bash
git clone https://github.com/cliver-project/CLIver.git
cd CLIver

make init          # venv + workspace dependencies
make init-local    # + optional local model backends
make test          # run both packages' tests
```
