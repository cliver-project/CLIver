## Requirements

- **Python 3.10+**
- An API key for at least one LLM provider (or a local endpoint)

## Install cliver-core

`0.3.0` is the first stable release of the 0.3 API series: the public API is frozen, with bug
fixes only in `0.3.x` patch releases. Pin the exact version when your deployment needs
reproducibility:

```bash
pip install cliver-core==0.3.0
```

The core package includes the MCP client (stdio and streamable HTTP). See
[Stability & Versioning](../stability/) for the support policy.

## Optional local models

In-process embedding, rerank, and System One backends pull torch, so they are opt-in:

```bash
pip install "cliver-core[local-st]==0.3.0"     # sentence-transformers embeddings
pip install "cliver-core[local-flag]==0.3.0"   # FlagEmbedding embeddings + rerank
pip install "cliver-core[local]==0.3.0"        # all three local backends
```

## Verify Installation

```bash
python -c "from cliver_core import AgentCore; print(AgentCore)"
```

## Work on the workspace

The repository is a uv workspace with two packages: `cliver-core` and the `cliver` CLI
application.

```bash
git clone https://github.com/cliver-project/CLIver.git
cd CLIver

make init          # venv + workspace dependencies
make init-local    # + optional local model backends
make test          # run both packages' tests
```
